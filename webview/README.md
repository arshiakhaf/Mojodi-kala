# پوسته Android WebView موجودی‌کالا

این پوشه یک پروژه آماده Android Studio برای تبدیل سایت به اپلیکیشن WebView است.

## استفاده

1. پوشه `webview` را در Android Studio باز کنید.
2. در `app/build.gradle` مقدار `SITE_URL` را با آدرس نهایی هاست جایگزین کنید.
3. Sync Gradle و سپس Run یا Build APK را بزنید.

برای تست روی شبیه‌ساز اندروید، اگر سایت با `php -S 0.0.0.0:8000` روی کامپیوتر اجرا شده است، می‌توانید موقتاً مقدار زیر را بگذارید:

```gradle
buildConfigField 'String', 'SITE_URL', '"http://10.0.2.2:8000/index.php"'
```

مجوز اینترنت، بازگشت با دکمه Back و لینک‌های `tel:` در این نمونه آماده شده‌اند. قبل از انتشار، آدرس دامنه واقعی، آیکن برند، نام بسته و امضای Release را تنظیم کنید.
