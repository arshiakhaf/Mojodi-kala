# موجودی‌کالا — دموی PHP واکنش‌گرا

یک نمونه‌کار فارسی و راست‌چین برای جست‌وجو و مقایسه موجودی کالا/قطعات از میان فروشندگان مختلف. ظاهر صفحه از سادگی و نظم سامانه‌های مدیریتی الهام گرفته شده و روند جست‌وجو، فیلتر و دیدن پیشنهادها بر اساس ساختار دموی «محصول‌یاب» طراحی شده است.

## امکانات دموی فعلی

- صفحه اصلی RTL با طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل
- جست‌وجو با نام کالا، مدل خودرو، برند، کد و عبارت‌های نمونه
- جست‌وجوی حرفه‌ای با فیلتر شهر، دسته‌بندی، برند، وضعیت، مهلت تست، گارانتی و نوع پرداخت
- نمایش کارت‌های موجودی و قیمت شروع هر کالا
- پنجره جزئیات هر کالا با پیشنهاد فروشندگان، شهر، شرایط و لینک تماس آزمایشی
- منوی موبایل، اسکرول نرم، وضعیت بدون نتیجه و هشدار معامله
- داده‌ها و تصاویر کاملاً آزمایشی و محلی، بدون وابستگی به سرویس خارجی برای نمایش تصاویر
- پوشه `webview/` شامل پوسته آماده Android Studio برای تبدیل سایت به اپلیکیشن WebView

## اجرای سایت

نیازمندی: PHP 7.4 یا بالاتر.

```bash
php -S 0.0.0.0:8000
```

سپس در مرورگر بروید به:

```text
http://localhost:8000/index.php
```

برای اجرای نسخه واقعی روی Apache یا Nginx، کافی است ریشه پروژه را روی هاست PHP قرار دهید؛ این نسخه دیتابیس لازم ندارد و داده‌های آزمایشی در `includes/data.php` قرار گرفته‌اند.

## پیش‌نمایش در محیطی که PHP نصب نیست

یک سرور اختیاری PHP-Wasm هم در پروژه قرار دارد تا همان `index.php` را بدون نصب PHP اجرا کند:

```bash
npm install
npm run preview
```

سپس `http://localhost:8000` را باز کنید. جزئیات این روش در `preview-server.md` آمده است.

## ساختار مهم

```text
index.php                         صفحه اصلی و فیلتر سمت سرور
includes/data.php                 کالاها و پیشنهادهای آزمایشی
assets/css/style.css              طراحی و breakpointهای موبایل
assets/js/app.js                  منوی موبایل و پنجره جزئیات کالا
assets/images/                    تصاویر SVG آزمایشی محلی
webview/                          پروژه Android WebView
```

## اتصال به نسخه واقعی

در مرحله بعد می‌توان آرایه‌ی `includes/data.php` را با جداول MySQL یا API جایگزین کرد. پیشنهاد جداول اصلی:

- `products`: نام، کد، دسته‌بندی، برند، مدل خودرو و تصویر
- `sellers`: نام فروشگاه، شهر، تلفن و وضعیت تأیید
- `offers`: شناسه کالا، قیمت، وضعیت، گارانتی، مهلت تست و نوع پرداخت

قبل از انتشار عمومی، احراز هویت فروشنده، اعتبارسنجی سمت سرور، CSRF، محدودسازی درخواست‌ها و سیاست حریم خصوصی اضافه شود. شماره‌های تماس و قیمت‌های داخل این نسخه صرفاً نمونه هستند.
