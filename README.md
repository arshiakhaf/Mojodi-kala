# موجودی‌کالا — نسخه کامل PHP واکنش‌گرا

یک نمونه‌کار فارسی و راست‌چین برای جست‌وجو، مقایسه و مدیریت موجودی کالا/قطعات از میان فروشندگان مختلف. ظاهر صفحه از سادگی و نظم سامانه‌های مدیریتی الهام گرفته شده و روند جست‌وجو، فیلتر و مقایسه پیشنهادها بر اساس ساختار دموی «محصول‌یاب» طراحی شده است.

## امکانات نسخه کامل

### بخش عمومی

- صفحه اصلی RTL و واکنش‌گرا برای دسکتاپ، تبلت و موبایل
- جست‌وجو با نام کالا، مدل خودرو، برند، کد و عبارت‌های نمونه
- جست‌وجوی حرفه‌ای با فیلتر شهر، دسته‌بندی، برند، وضعیت، مهلت تست، گارانتی و نوع پرداخت
- نمایش کارت‌های کالا با قیمت شروع، تعداد پیشنهاد و شهرهای موجود
- صفحه جزئیات مستقل برای هر کالا در `product.php?id=...`
- پنجره جزئیات سریع با فهرست پیشنهاد فروشندگان
- لینک تماس مستقیم با فروشنده از نوع `tel:`
- وضعیت بدون نتیجه، اسکرول نرم، منوی موبایل و هشدارهای معامله

### پنل فروشنده

- ورود فروشنده با Session امن و خروج از حساب
- ثبت‌نام فروشگاه و اعتبارسنجی فرم
- ثبت پیشنهاد جدید برای کالا
- ثبت شهر، قیمت، وضعیت، گارانتی، مهلت تست و نوع پرداخت
- مشاهده پیشنهادهای ثبت‌شده در پنل
- حذف پیشنهاد فقط توسط صاحب همان پیشنهاد
- وضعیت «در حال بررسی» برای پیشنهادهای جدید
- ورود آزمایشی آماده برای ارائه:

```text
شماره: 09120000001
رمز: demo1234
```

### فنی و بهینه‌سازی

- SQLite با ساخت خودکار جداول و Seed اولیه؛ بدون نیاز به نصب و Import دستی دیتابیس
- fallback به داده‌های `includes/data.php` در صورتی که SQLite روی هاست فعال نباشد
- API جست‌وجوی کالا در `api/products.php`
- API سلامت سرویس در `api/health.php`
- Prepared Statement برای عملیات دیتابیس
- CSRF Token، Session Cookie امن، اعتبارسنجی ورودی و کنترل دسترسی حذف
- هدرهای امنیتی پایه و جلوگیری از فهرست‌شدن پوشه‌ها در Apache
- تصاویر SVG محلی و کم‌حجم، بدون وابستگی ضروری به تصاویر خارجی
- Cache مناسب برای فایل‌های CSS، JavaScript و SVG در Apache
- سرور پیش‌نمایش اختیاری PHP-Wasm برای محیطی که PHP CLI ندارد

## اجرای سایت با PHP

نیازمندی: PHP 7.4 یا بالاتر. برای فعال‌شدن پنل کامل، افزونه `pdo_sqlite` نیز پیشنهاد می‌شود.

```bash
php -S 0.0.0.0:8000
```

سپس در مرورگر بروید به:

```text
http://localhost:8000/index.php
```

در اولین اجرا، دیتابیس نمونه به شکل خودکار در مسیر زیر ساخته می‌شود:

```text
storage/mojodi.sqlite
```

پوشه `storage` باید روی هاست قابل نوشتن باشد. فایل دیتابیس و Sessionها در Git نادیده گرفته شده‌اند.

## پیش‌نمایش در محیطی که PHP نصب نیست

```bash
npm install
npm run preview
```

سپس `http://localhost:8000` را باز کنید. این روش همان فایل‌های PHP را با PHP-Wasm اجرا می‌کند؛ راهنمای آن در `preview-server.md` آمده است.

## نسخه مستقل برای کارفرما

برای ارائه بدون هاست و بدون PHP، فایل زیر را با مرورگر باز کنید:

```text
demo.html
```

این فایل CSS، JavaScript، تصاویر و اطلاعات نمونه لازم برای نمایش صفحه عمومی را در خودش دارد. تصاویر آماده ارائه نیز در مسیر زیر هستند:

```text
demos/desktop-preview.png
demos/mobile-preview.png
```

## ساختار مهم

```text
index.php                         صفحه اصلی و فیلتر سمت سرور
product.php                       صفحه جزئیات کامل کالا
login.php                         ورود و ثبت‌نام فروشنده
dashboard.php                     پنل مدیریت پیشنهادهای فروشنده
logout.php                        خروج از حساب
api/products.php                  API جست‌وجو و فهرست کالا
api/health.php                    API بررسی سلامت سرویس
includes/bootstrap.php            Session، دیتابیس، احراز هویت و Repository
includes/data.php                 کالاها و پیشنهادهای آزمایشی
database/schema.sql               Schema مرجع SQLite
storage/                          محل دیتابیس و Sessionهای runtime
assets/css/style.css              طراحی صفحه عمومی
assets/css/portal.css             طراحی پنل، ورود و جزئیات
assets/js/app.js                  منوی موبایل و پنجره جزئیات
assets/images/                    تصاویر SVG آزمایشی محلی
demo.html                         نسخه مستقل HTML برای ارائه
demos/                            تصاویر پیش‌نمایش دسکتاپ و موبایل
webview/                          پروژه Android WebView
```

## اتصال به نسخه واقعی

در نسخه عملیاتی می‌توان Seed نمونه را حذف و داده‌ها را از پنل مدیریت یا API واقعی وارد کرد. جداول اصلی عبارت‌اند از:

- `products`: نام، کد، دسته‌بندی، برند، مدل خودرو و تصویر
- `users`: فروشنده، شماره، شهر، رمز هش‌شده و نقش
- `offers`: کالا، فروشنده، قیمت، وضعیت، گارانتی، مهلت تست و نوع پرداخت

قبل از انتشار عمومی، احراز هویت چندمرحله‌ای، محدودسازی نرخ درخواست، لاگ‌گذاری، پشتیبان‌گیری، سیاست حریم خصوصی و درگاه پرداخت واقعی اضافه شود. شماره‌های تماس، قیمت‌ها و تصاویر داخل این نسخه صرفاً نمونه هستند.

## WebView Android

پروژه آماده Android Studio در مسیر `webview/` قرار دارد. مقدار `SITE_URL` را در `webview/app/build.gradle` با دامنه نهایی جایگزین کنید و سپس APK را از Android Studio بسازید. WebView شامل مجوز اینترنت، مدیریت دکمه Back و بازکردن لینک‌های تلفنی است.

## منابع بررسی‌شده

صفحه عمومی `demo.mahsolyab.ir` قابل مشاهده بود و الگوی «جست‌وجوی ساده/حرفه‌ای، فهرست کالا و پیشنهادهای فروشنده» از آن برداشت شد. صفحه `modirap.ir` نیز برای الهام از ساختار مرتب، هدر ساده، معرفی مزایا و CTA استفاده شد. لینک فایل پارس‌کدرز به فرم ورود هدایت شد و محتوای فایل بدون احراز هویت قابل دریافت نبود.

لینک Google Drive ویدیو نیز در این محیط با خطای دسترسی/ارتباط قابل دریافت نشد؛ برای تطبیق دقیق با جزئیات ویدیو، فایل ویدیو یا چند اسکرین‌شات از آن باید در خود گفتگو بارگذاری شود.
