# بسته دمو برای ارائه به کارفرما

این پوشه خروجی‌های آماده ارائه از دموی موجودی‌کالا را نگه می‌دارد:

- `desktop-preview.png` — تصویر نمای دسکتاپ در ابعاد ۱۶۰۰×۱۰۸۰
- `mobile-preview.png` — تصویر نمای موبایل در ابعاد ۷۲۰×۱۳۲۰

فایل HTML مستقل در ریشه پروژه با نام `demo.html` قرار دارد. این فایل CSS، JavaScript، تصاویر آزمایشی و داده‌های نمونه لازم را داخل خودش دارد و می‌توان آن را مستقیماً با مرورگر باز کرد؛ برای نمایش اولیه به نصب PHP یا دیتابیس نیاز ندارد.
